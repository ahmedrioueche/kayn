# Acceptance Criteria — KAYN

## Visual
- [ ] Hero communicates premium Algerian car rental immediately.
- [ ] Typography and spacing feel intentional.
- [ ] Vehicle photography is consistent and high quality.
- [ ] One coherent color theme is used throughout.
- [ ] Mobile layout feels intentionally designed.

## Product
- [ ] Visitors understand the rental proposition.
- [ ] Four vehicles can be discovered and compared.
- [ ] Prices and core specifications are visible.
- [ ] Cities are clearly presented.
- [ ] Reservation/contact CTA is obvious.
- [ ] Ordering process is understandable.

## Engineering
- [ ] Tailwind CSS v4 conventions are used.
- [ ] User-facing strings use i18n.
- [ ] No duplicated hardcoded business content.
- [ ] No arbitrary theme colors.
- [ ] No unnecessary client-side code.
- [ ] Components/pages remain maintainable.
- [ ] No horizontal overflow.
- [ ] Accessibility basics are implemented.
- [ ] Reduced-motion behavior works.
- [ ] Lint/typecheck/build pass.
