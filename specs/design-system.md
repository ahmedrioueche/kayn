# Design System — KAYN

## Direction
Modern Algerian mobility brand with premium automotive/editorial design.

Think:
- automotive editorial site
- dark sophisticated canvas
- high-quality vehicle photography
- bold typography
- clear product information
- confident but practical

Avoid:
- generic SaaS styling
- excessive glassmorphism
- random colors
- rainbow gradients
- crowded marketplace UI
- unnecessary decoration

## Theme tokens
Background: #0B0D0F
Surface: #14171A
Elevated surface: #1C2024
Foreground: #F5F3EF
Muted: #A8ADB3
Border: #2A2F34
Accent: #C8A45D
Accent foreground: #111111

Use the accent sparingly for primary CTA, active states, selected information, and small highlights.

No additional arbitrary colors.

## Typography
Recommended:
- Display: Manrope or Plus Jakarta Sans
- Body/UI: Inter or Manrope

Use strong display typography in the hero and concise metadata labels in cards.

## Layout
- Max width: approximately 1200–1280px.
- Generous section spacing.
- Strong image/text balance.
- Product-card composition rather than generic cards.
- Consistent spacing scale.
- Consistent radius scale.
- Consistent border and elevation treatment.

## Images
Vehicle photography is a core visual asset.

Prefer consistent editorial/studio images with attractive three-quarter views.

Avoid combining incompatible image styles.

## Motion
Framer Motion may be used for:
- hero reveal
- section reveal
- vehicle-card entrance
- image hover
- mobile-menu transition
- CTA micro-interactions

Prefer transform/opacity animations. Respect reduced motion.

## Reusable UI
Use shared patterns for:
- buttons
- cards
- typography
- section headings
- metadata rows
- focus states
- motion wrappers
